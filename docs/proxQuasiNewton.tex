\section{Problem specification}
At every time iteration of the time evolution of system of interest, $N$ particle that lie in a threshold are identified as possibly colliding within the time stepping window. This motivates solving the following a linear complimentary problem
\[\A\x -\b \perp \x = 0\]
where $\A \in \mathbb{R}^{n \times n}, \b \in \mathbb{R}^n$. Depending on how the problem is set up $n=N$ or $n=3N$. In the later case, each possible contact is given three degrees of freedom to allow for non-tangential forces. The values of $\x$ either satisfy a linear system or are element-wise 0. Physically $\x$ corresponds to forces and torques acting on individual particle from a collision. If the particles collide, then the forces are nonzero, but if the particles do not collide then the collisional forces are zero.

For small-medium systems, it has been observed that active set methods or interior point methods are reasonable choice for solving the LCP, but when the system becomes large these methods become computationally infeasible. Instead, proximal gradient descent methods are utilized. We hypothesize that this is not due to the supremacy in this regime, but rather that they are a robust and were the simplest to implement. Instead we believe that there is still computational advantage on the table for proximal quasi Newton methods. 

Solving the LCP is equivalent to solving the following constrained quadratic program. This can be seen by deriving the KKT conditions and matching them with the above statements for the LCP.
\begin{equation} \label{eq:qp}
    \x^* = \argmin_{\x \geq 0 } \bigl\langle \x, \tfrac{1}{2}\A\x +\b\bigr\rangle
\end{equation}

Due to the size of systems of interests, it is not computationally efficient to store the matrix $\A$ . Thus, only a matrix-vector product is available. Each mat-vec involves solving from boundary integrals on each particle. These integrals solve the the Stokes equations to obtain forces of the fluid flow acting on each particle. 

This motivate finding optimization problems that solve Equation \eqref{eq:qp} with as few applications of the matrix $\A$ as possible. For large systems, it is standard to apply projected (proximal) gradient descent. The choice of search direction comes from approximating the cost function with the following quadratic model:
\[ \x_{k+1} = \underset{\x \geq 0}{\argmin} \langle \nabla f(\x_k), \x-\x_k \rangle + \tfrac{L}{2}\langle \x-\x_k , \x-\x_k \rangle\]
Implicitly, the Hessian is being approximated by the scaled identity $L \mathbf{I}$ where $L$ is the Lipschitz constant of the Hessian which in our case is the largest singular value of $\A$. From standard convergence theory, we know that the rate of convergence in the unconstrained case is $\mathcal{O}(\kappa(\A)N /\epsilon)$ where $\kappa(\A)$ is the condition number of the matrix $\A$ and $\epsilon$ is the desired tolerance of the approximation. 

We believe this can be improved by leveraging the fact that for quadratic program the Hessian is constant, thus using curvature information should bring significant improvements on the rate of convergence. Because $\A$ is not explicitly available and inverting with a Krylov method would make the cost of each iteration prohibitive. Thus approximating the pertinent curvature information with a quasi-Newton method seems appropriate. Specifically, will attempt to solve the problem quadratic approximation to Equation \eqref{eq:qp} at the current iterate $\x_k$ for 
\begin{equation}
    \x_{k+1} = \underset{\x \geq 0}{\argmin} \langle \nabla f(\x_k), \x-\x_k \rangle + \tfrac{1}{2}\langle \x-\x_k , \B_k(\x-\x_k )\rangle
\end{equation}
Notice that this allows for a different approximation to the Cauchy (gradient descent) step, without increasing the number of mat-vec's used. In particular, in the unconstrained case this increases the cost of the each iteration by $\mathcal{O}(nr)$ where $r$ is the memory of the quasi-Newton approximation. 

Some approaches such at Projected Quasi-Newton (PQN), suggest an approximating the solution to this problem by taking the step (sweeping some details under the rug)
\[ \x_{k+1} = \max\bigl(0, x_k  - \H_k \nabla f(\x_k)\bigr)\]
While this method makes us of some curvature information, it is not making full use of Hessian approximation with regards to finding the best next iterate in the feasible set. Explicitly, we believe that we should be taking 
\[ \x_{k+1} = \prox_{\x \geq0}^{\B_k} \bigl( x_k  - \H_k \nabla f(\x_k)\bigr)\]
The proximal operator needs to be applied with respect to the norm induced by $\B$. In general, this requires that we solve another constrained quadratic program of the same size but by leveraging structure of the low-rank updates of $\B_k$, we can solve a significantly smaller dual problem. In the special zero memory case with the SR1 update, this involves finding the root of monotonic piecewise linear function which can be solved in $\mathcal{O}(n\log(n))$ time. In the general case, the dual problem reduces to optimizing over an unconstrained piecewise quadratic program (equivalently rootfinding of a $r$ dimensional piecewise linear function). While this increases the cost per step of the our proximal quasi-Newton method we believe that fewer iteration in general are necessary to converge for problems of interest. As the computational burden lies on the number of mat-vecs, the cost of solving the subproblem induced by the weighted-proximal operator is worth it. 

\section{Step Size}
For the unconstrained case, once a search direction $\p_k$ is chosen an optimal step size can be computed with the cost of one extra mat-vec: 
\[\alpha^* = \argmin_\alpha \bigl\langle \x_k - \alpha\p_k, \tfrac{1}{2}\A(\x_k - \alpha\p_k) +\b\bigr\rangle = -\frac{\langle \nabla f_k, \p_k\rangle }{\langle \p_k,\A\p_k\rangle}\]
So for the price of one extra mat-vec the optimal step size can be computed explicitly. 

In the constrained case, the following iteration could be used 
\begin{align*}
    \p_k &= \H_k \nabla f_k &\text{(Quasi-Newton Step Direction)}\\
    \alpha^*_k &= -\frac{\langle \nabla f_k, \p_k\rangle }{\langle \p_k,\A\p_k\rangle} &\text{(Unconstrained Optimal Step Size)}\\
    \bar{\x}_k &= \prox_{\x\geq 0}^{\B_k}(\x_k +\alpha^*_k \p_k) &\text{(Apply Proximal Operator)}\\
    \q_k &= \bar{\x}_k - \x_k &\text{(Feasible Step Direction)}\\
    \eta_k^* &= \min\left(1,  -\frac{\langle \nabla f_k, \q_k\rangle }{\langle \q_k,\A\q_k\rangle}\right) &\text{(\emph{Semi}-Optimal Feasible Step Size)} \\
    \x_{k+1} &= \x_k + \eta_k^* \q_k &\text{(Next Iterate)} 
\end{align*}
More testing and analytic compution is require to demonstrate whether the additional mat-vecs per iteration are necessary. 

In the literature it has been shown for quasi-Newton methods (without limited memory) that $\alpha^* \rightarrow 1$. As we are in the limited memory regime it is less clear as wether this will be the case. 

\section{Hessian Approximation}

At each iteration the distance between the two most recent iterates and gradients are specified as 
\[\s = \x_k - \x_{k-1} \;\mathrm{ and } \;\y = \nabla f_k - \nabla f_{k-1} \;\mathrm{respectively.}\]
The goal is at each iteration is improve the approximation to the inverse Hessian $\H \approx \nabla^2 f_k ^{-1}$ that satisfies the secant condition $\H \y = \s$.

In the unconstrained case, we only need to apply the matrix vector product $\H_k \cdot$. There are different approaches, but in the limited memory case it is standard to save the vectors $\{\s_j, \y_j\}_{j=k-r}^{k}$. This allows for a relatively fast matrix vector product computation of $O(N r)$, but for the proximal operator we need to represent the Hessian approximation as a diagonal plus a rank $r$ update $\B = \B_0^{-1} - \V\V^T$. If we choose to use the SR1 update we have that 
\begin{align*}
    \mathbf{S} &= [\s_{k-r} \; \cdots\;\s_k],\;
    \mathbf{Y} = [\y_{k-r}\;\cdots \;\y_k]\\
    (\mathbf{A})_{ij} &= 
        \langle \s_{k-r+i-1}, \y_{k-r+j-1}\rangle\\
    \B_k &= \B_0 +\left(\mathbf{Y}-\B_0 \mathbf{S}\right)\left(\mathbf{A}-\mathbf{S}^T \B_0 \mathbf{S}\right)^{-1}\left(\mathbf{Y}-\B_0 \mathbf{S}\right)^T,\\
\end{align*}

\subsection{SR1}
The symmetric rank 1 (SR1) update is 
\[\gamma \in (0,1], \; \tau_{BB_2} = \frac{\langle\s, \y\rangle}{\|\y\|^2} > 0, \; h_0 = \gamma \tau_{BB_2},\; \Hnaut = h_0 I, \]
\[\u = \frac{\s - \Hnaut \y}{ \sqrt{\sigma \langle \s - \Hnaut \y, \y\rangle}},\;\H = \Hnaut + \sigma \u \u^T.\; \]
where $\sigma = \operatorname{sign}[\langle \s - \Hnaut \y, \y\rangle] \in \{-1,1\}$. This allows for the update to either be the addition or subtraction of a rank one matrix.Nocedal and Wright (page 145) specify that SR1 is compelling for the following reasons
\begin{itemize}
    \item There are simple fast ways to check for numerical break downs of the method compared to BFGS (which requires damping in the constrained case). 
    \item Because we are minimizing a quadratic, the Hessian of the objective is constant, and the Hessian approximations generated by the SR1 are often better than the BFGS approximations.
    \item For a constrained problem, imposing the curvature condition  $y_k^T s_k>0$ is often impossible, and thus BFGS updating is not recommended. Indefinite Hessian approximations are desirable insofar as they reflect indefiniteness in the true Hessian.
\end{itemize}
\subsection{BFGS}
$\Hnaut$ is chosen in the same way as for the SR1 update, and thus $\Bnaut$ is specified as well. 

This is a rank-2 update at every step: 
\[\B_{k+1} = \B_k + \u^{(1)}_k\u^{(1)^T}_k - \u^{(2)}_k\u^{(2)^T}_k\]
\[\u_k^{(1)} = \frac{\y_k }{\sqrt{ \langle \y_k,\s_k\rangle}}, \;\u_k^{(2)} = \frac{\B_k \s_k }{\sqrt{ \langle \s_k, \B_k \s_k \rangle}}\]
There are some 
\begin{itemize}
    \item BFGS guarantees that the Hessian approximation stays positive definite
    \item No need for a trust region subproblem at each iteration
\end{itemize}


\section{Proximal Step}
The non-smooth function of interest is simply the indicator function of the positive orthant:
\begin{equation} \label{eq:h}
    h(\x) =\begin{cases}
        0,&\x \geq 0\\
        \infty,&\text{otherwise}
    \end{cases}
\end{equation}
With the inner product induced by the identity matrix, this defines the separable proximal operator 
\begin{equation} \label{eq:prox}
    \prox_h(\y) = \argmin_{\x\geq 0} \|\x-\y\|_2^2 = \bigl(\max(x_i,0)\bigr)_{i=1}^n.
\end{equation}

Specializing to our case, we can take the results of Theorem 3.8 of Becker and Fadili:
\[\prox_h^\B(\y) = \prox_h(\y + \sigma \alpha^{\star} \Hnaut \w)\]
where $\alpha^{\star}$ is the unique root of
\[\mathcal{L}(\alpha)= \left\langle \w, \y - \prox_h (\y + \sigma \alpha \Hnaut \w)\right\rangle + \alpha.\]
The theorem guarantees that $\mathcal{L}$ is monotonically increasing, and notice that it is also piecewise linear. The root can be efficiently found by first finding the points $\boldsymbol{\alpha_n}$ where  $\mathcal{L}$ is changes slope. 
\[\boldsymbol{\alpha_n} = -\sigma \left( \frac{x_i}{h_0 w_i}\right)_{i=1}^n\]
This list can then be sorted $\hat{\boldsymbol{\alpha}} = \operatorname{sort}(\boldsymbol{\alpha})$. Thus, computing the values of $\bigl(\mathcal{L}(\hat{\alpha}_i)\bigr)_{i=1}^n$ facilitates an efficient algorithm to find $\alpha^*$. If all $\mathcal{L}(\hat{\alpha}_n) < 0$, then we know that the root occurs for $\alpha^* > \hat{\alpha}_n$. By a symmetric argument if $\mathcal{L}(\hat{\alpha}_1) > 0$, then $\alpha^* < \hat{\alpha}$. In the non-trivial case where $\mathcal{L}(\hat{\alpha}_i) < 0 < \mathcal{L}(\hat{\alpha}_{i+1})$ then the root will occur in the specified interval $\alpha^* \in (\hat{\alpha}_i,\hat{\alpha}_{i+1})$. Notice that the proximal operator for $h$ will threshold the same indices of $\boldsymbol{\lambda} =: \y + \sigma \alpha \Hnaut \w$ for all values of $\alpha\in (\hat{\alpha}_i,\hat{\alpha}_{i+1})$. All values that are positive values $\lambda(\hat{\alpha}_i)_j > 0$ are guaranteed to stay positive, also we can identify values of $\lambda(\hat{\alpha}_i)_j = 0$ that will increase over the interval with respect to $\alpha$ $(\Hnaut \w )_i \geq 0$. Next, using $\hat{\alpha}_i$ identify which indices are thresholded to 0. This defines the indexing operator 
\[\bigl(\mathcal{P}_i(\mathbf{z})\bigr)_j = \begin{cases}
    z_j, & (\boldsymbol{\lambda}(\alpha_i))_j > 0 \;\mathrm{or}\\ & \bigl((\boldsymbol{\lambda}(\alpha_i))_j = 0 \; \mathrm{and}\; \sigma (\Hnaut \w)_j > 0\bigr)  \\
    0, & \text{otherwise}
\end{cases}  \]
This allows us to investigate $\mathcal{L}$ on each interval: 
\[ \mathcal{L}(\alpha) = \begin{cases}
    \langle \w, \y\rangle + \alpha, & \alpha < \hat{\alpha}_1\\
    \langle \w, \y\rangle - \langle \mathcal{P}_i(\w), \mathcal{P}_i(\y - \sigma \alpha \Hnaut \w) \rangle + \alpha, & \alpha \in [\hat{\alpha}_i,\hat{\alpha}_{i+1}]\\
    \alpha (1 - \langle \w, \Hnaut \w \rangle ), & \hat{\alpha}_n < \alpha\\
\end{cases}\]
We can obtain the optimal value $\alpha^*$ by solving for the root of the linear equation on specified interval $i$ 
\[ \alpha^* = \begin{cases}
    -\langle \w, \y\rangle, & \mathcal{L}(\hat{\alpha}_n)< 0 \\
    \frac{\langle \w, \y\rangle - \langle \mathcal{P}_i(\w), \mathcal{P}_i(\y)\rangle }{\sigma\langle \mathcal{P}_i(\w), \mathcal{P}_i(  \Hnaut \w) \rangle -1}, & \mathcal{L}(\hat{\alpha}_i) < 0 < \mathcal{L}(\hat{\alpha}_{i+1})\\
    0, & 0 < \mathcal{L}(\hat{\alpha}_1) \\
\end{cases}\]

Thus 
\[\x^* = \prox_h(\y - \sigma \alpha^* \Hnaut \w)\]
